## 📌 Projetos

### 🎨 Vitrinarte

Plataforma desenvolvida para funcionar como uma **vitrine digital para artistas**, permitindo apresentar obras, organizar trabalhos e facilitar o contato entre artistas e interessados.

**Tecnologias:** Python, Flask, Bootstrap e SQL.

---

### 🏥 Web Saúde

Sistema web desenvolvido para centralizar informações sobre unidades de saúde da cidade de Picos - PI.

**Tecnologias:** React, Next.js e Bootstrap.

---

### 📦 Spumar

Aplicação mobile para **gerenciamento de pedidos**, permitindo cadastrar clientes, produtos, valores, datas de entrega, observações e acompanhar o status dos pedidos.

**Tecnologias:** React Native, Expo, TypeScript e SQL.
